# dsh-diary-template

给你的 AI 加一本「每日日记」的最小模板。

写好之后，它会每天 22:30 自己记一笔：今天做了什么、哪里判断错了、什么没解决、倾向怎么处理。
第二天新会话的它，靠这本日记把昨天接上。

## 适用 / 不适用

| | 情况 |
| --- | --- |
| ✅ 能用 | 你在用 **DeepSeek Harness（DSH）**，AI 能读写你电脑上的文件 |
| ❌ 用不了 | 只用网页版 / App 的 DeepSeek——它没有文件系统，也没有定时任务 |

网页版用户请用 [`prompt.md`](prompt.md) 里的手动方案。

## 三步装好

### 1. 放文件

把 `AGENTS.md` 复制到你 DSH 的工作区根目录。

> 不知道工作区在哪？问 AI：「我的工作区路径是什么」。

### 2. 建目录

```
diary/
```

不用建文件，目录空着就行。

### 3. 跟 AI 说一句

```
读一下 AGENTS.md，然后每天 22:30 写日记，格式按里面来。
```

它会自己把定时任务建起来（DSH 有 `schedule_create` 工具）。

## 验证

第二天打开 `diary/` 看一眼，应该有 `2026-11-02.md` 这样的文件。

没出现的话，检查两件事：

1. DSH 那天有没有开着（**定时任务只在进程运行时触发**）
2. 日记路径对不对（`diary/` 要在工作区根目录）

## 为什么是四段

| 段落 | 解决什么问题 |
| --- | --- |
| 今天发生了什么 | 防止"聊了聊"这种空话——逼它写具体的人、事、报错 |
| 我的判断 | 把"有把握"和"猜的"分开，猜错的也留证据 |
| 没解决的 | 第二天知道从哪儿接着干 |
| 我的倾向 | 唯一能写"感觉"的地方，但要求是**不编情绪** |

最后一段是关键：**宁可不写，也不写假的。**

## 一个提醒

这本日记**不会**让 AI 记住一切。上下文一压缩，它照样会忘。

日记的作用是：**忘掉之后，还能捡回来。**
